# Огородный кликер — заготовка для VK Mini Apps

Неполная заготовка интерфейса игры про выращивание урожая: в HTML есть элементы
для урожая, солнца, улучшения грядки и нового сезона. Наличие этих кнопок
не подтверждает реализацию игровых механик.

## Состав и состояние

В репозитории находятся `index.html`, `vk-bridge.min.js` и этот README.
HTML ссылается на отсутствующие `css/style.css` и 16 модулей в `js/`.
Из этого клона нельзя запустить полноценную игру.

Ближайший шаг — добавить стили и игровые модули, проверить запуск и после этого
опубликовать тестовую ссылку. Дата релиза пока не определена.
